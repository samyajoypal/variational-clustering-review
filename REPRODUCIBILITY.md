# Reproduction guide

## Numerical reports

Use the quick start in the README. `scripts/reproduce_report.py` verifies an explicit public analysis-manifest SHA256, validates complete seed groups and generates six numerical CSV tables and 18 figures. `generated/` is ignored by Git; choose a new output directory for each run.

Scientific values in the exported analysis are unchanged. Operational locations were replaced by portable identifiers, so public file hashes differ from the originals. `provenance/export_bindings.json` records the identities and source adaptations; `provenance/public_manifest.json` binds the distributed bytes. Original audit digests identify retained original evidence, not checksums of public derivatives. These are integrity records, not cryptographic authorship authentication.

The original matched protocol is `paper1-air-matched-final-v1`, SHA256 `c44ad7e7db6cc73ee80793d56b0b63424fd51d5e7e9f4036eed8986b481e9cde`. It comprises 40 initializations, 300 fits and 1,200 prediction panels. Four interrupted fits continued as the same seeds, not additional replications. All completed seed groups and all specified outcomes are retained.

The model equations, numeric settings, optimization and metric definitions are preserved. Public operational adaptations remove infrastructure identity checks and private metadata, relocate a reference-protocol document and supply a synthetic roster fixture for tests. Their changed source hashes are explicitly recorded. The original completion evidence is not claimed to have been generated by these adapted source bytes.

Probability rows must be finite, nonnegative and within the frozen `1e-5` mass tolerance. Accepted rows are normalized in float64 and their unchanged hard assignments are checked. Raw predictions are not rewritten. Per-array diagnostics remain in the evaluation.

Additional plots use the included scientific summaries:

```bash
python scripts/plot_simulations.py --summary results/paper1_review_20261028/scientific_analysis_complete_v2/scientific_simulations.json --output generated/simulations --version complete_v2
python scripts/plot_references.py --evaluation results/paper1_review_20261029/reference_analysis_complete_v2/evaluation.json --output generated/reference_figures
```

## Fresh experiment runs

`requirements-training.txt` records direct versions used with Python 3.9.25, PyTorch 2.8.0+cu128 and CUDA 12.8. Select a compatible CUDA wheel/driver for the host. Presentation used the separate versions in `requirements-report.txt`. These files do not claim a complete transitive lock; recorded versions are in `provenance/environment_observations.json`.

Prepare data following [DATA.md](DATA.md). A complete clean fit uses the original budgets:

```bash
python -m experiments.paper1_review.final_runner initialize --manifest prepared_data/mnist/manifest.json --seed 101 --device cuda --output runs/mnist/seed101/initial
python -m experiments.paper1_review.final_runner train --manifest prepared_data/mnist/manifest.json --seed 101 --device cuda --initial runs/mnist/seed101/initial --method student_q_student_prior --output runs/mnist/seed101/student_fit
python -m experiments.paper1_review.final_runner predict --manifest prepared_data/mnist/manifest.json --device cuda --fitted runs/mnist/seed101/student_fit --split test --corruption clean --output runs/mnist/seed101/student_test
```

The allocation is in `workload.py`; numeric settings are in `final_protocol.py`. Preserve paired seeds, shared initializations and training views for the full comparison. New runs use new directories. Labels remain outside optimization and checkpoint selection. A short smoke run does not reproduce the full experiment, and cross-hardware bitwise equality is not promised.

For the complete workload specification, first create `generated/`, then run `python -m experiments.paper1_review.workload --output generated/workload_manifest.json`. The deterministic S1 diagnostic is `python -m experiments.paper1_review.score_assignment_diagnostic --output generated/s1`. Use `python -m experiments.paper1_review.simulations --list-supported` for S2/S3 configuration indices. Full tasks accept `--index`, `--manifest`, `--output` and `--device`; `--smoke` marks reduced nonpublication runs.

Separate reference adaptations use seeds 901–903. Fetch their pinned prerequisites before running the reference CLIs. [Reference protocols](protocols/reference_recipes.md) identify the source revisions and adaptations; they are not claims to reproduce historical leaderboard scores.

## Original prediction-level recomputation

The approximately 65 GB original audited run tree, input arrays and prediction/checkpoint arrays are not included. Repeating its complete artifact audit and metric computation requires that additional evidence. `experiments.paper1_review.audit_completed` and `evaluate_matched` retain source/configuration/hash/lineage gates, with private infrastructure identity checks removed. Supply independently trusted campaign, source, completion and continuation anchors for the particular evidence being evaluated. Relocation uses `--path-map` rather than silently changing archived identities.

The public contingencies, seed scores, paired rows and summary statistics permit independent numerical checks of the reported metrics and figures. Report regeneration does not repeat model fitting or the original bulk audit.
